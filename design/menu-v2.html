The nesting is not weak: it is inverted

Measured in your panel, inside the projects column. The session name starts five pixels to the left of its project's name. The child starts before the parent, and while the axis says that, no color and no weight will fix it.

37 · project 32 · session ~/work/… GITHUB-AcmePlatform ● github-acmeplatform-25 ● github-acmeplatform-9b

And there is a second reason, a quieter one. The session is called github-acmeplatform-25 inside a folder called GITHUB-AcmePlatform. 80% of the child's name is the parent's name, so both lines start the same way and the eye cannot find where one ends and the other begins.

Five ways to say it

The same three projects in all of them: one with two sessions, one empty, and one with a long, self-named session — which is where width gets tight.

— red: where the project starts · blue: where the session starts

What I would implement

  1. Indent sessions by 21 px, which is where the child's text lands to the right of the parent's text instead of to the left. It is the only change that fixes the problem on its own; the rest is reinforcement.
  2. A 1 px vertical guide from the header down to the last session. It costs one pixel and turns “they are below” into “they are inside”, which is what you want to read when a project has four sessions.
  3. Dim the repeated prefix on derived sessions — github-acmeplatform-25 — instead of deleting it. It gives back the tail, the only thing that tells one session from another, without taking away the full name when you need it to search or copy.
  4. None of this touches sessions with a name of their own. If you wrote it there is no prefix to dim, and the whole name reads as it is.
  5. Plainly: dimming gives back no width, deleting does. The indentation costs 21 px on the left. N5 wins them back with interest because the name goes from 19 characters to 2; the proposal wins back none — what it gains is that the tail stops hiding behind seventeen identical characters. If in use you find that width pinches harder than legibility, N5 is the same design with the prefix deleted instead of dimmed.
